# 面经编辑功能演示

## 功能演示流程

### 场景：完善一条刚处理完的面经

#### 步骤 1: 查看面经详情
```
操作：在历史记录列表中点击一条面经卡片
界面：进入面经详情页
显示：公司信息、面试问题、技术标签等
```

#### 步骤 2: 进入编辑模式
```
操作：点击右上角的"编辑"按钮
界面：弹出编辑模态框
显示：所有可编辑字段，填充当前数据
```

#### 步骤 3: 补充公司信息
```
操作：
1. 在"公司规模"下拉框中选择"大厂"
2. 在"面试阶段"下拉框中选择"一面"

效果：
- 下拉框显示选中的值
- 界面实时更新
```

#### 步骤 4: 添加技术标签
```
操作：
1. 在标签输入框中输入"React"
2. 按 Enter 键
3. 继续输入"TypeScript"并按 Enter
4. 输入"Hooks"并点击 + 按钮

效果：
- 每个标签立即显示在下方
- 显示为圆角徽章样式
- 可以点击 × 删除
```

#### 步骤 5: 编辑问题答案
```
操作：
1. 滚动到第一个问题
2. 在答案文本框中输入详细答案
3. 向下滚动到第二个问题
4. 补充更详细的答案

效果：
- 文本框自动调整高度
- 支持多行文本
- 可以自由编辑
```

#### 步骤 6: 添加新问题
```
操作：
1. 点击"添加问题"按钮
2. 在新问题卡片中输入："描述一下虚拟DOM的工作原理"
3. 在答案框中输入详细答案

效果：
- 新问题卡片追加到列表末尾
- 显示"问题 N"标题
- 包含完整的问题和答案编辑框
```

#### 步骤 7: 删除重复问题
```
操作：
1. 找到一个重复的问题
2. 点击问题卡片右上角的垃圾桶图标
3. 在确认对话框中点击"确定"

效果：
- 弹出确认对话框："确定要删除这个问题吗？"
- 点击确定后，问题立即从列表中移除
- 问题编号自动重新排序
```

#### 步骤 8: 保存修改
```
操作：
1. 检查所有修改
2. 点击右下角的"保存修改"按钮

效果：
- 按钮显示加载动画
- 文字变为"保存中..."
- 按钮和其他操作被禁用
```

#### 步骤 9: 查看更新结果
```
自动操作：
1. 保存成功后，编辑弹窗自动关闭
2. 返回面经详情页
3. 页面显示更新后的内容

显示：
- 公司规模：大厂
- 面试阶段：一面
- 新增的技术标签
- 补充的答案内容
- 新添加的问题
```

## 交互细节

### 输入框焦点效果
- 未聚焦：灰色边框
- 聚焦时：蓝色边框 (border-primary-500)
- 深色模式：自动调整颜色

### 按钮悬停效果
- 主按钮：背景色加深
- 次按钮：背景色变浅
- 删除按钮：显示红色高亮

### 标签交互
- 添加：淡入动画
- 删除：淡出动画
- 悬停：显示删除图标

### 问题卡片
- 默认：浅灰背景
- 悬停：边框高亮
- 删除按钮：仅悬停时显示

## 响应式适配

### 桌面端 (> 768px)
- 模态框：固定宽度 (max-w-4xl)
- 公司信息：两列布局
- 滚动：仅内容区域

### 移动端 (< 768px)
- 模态框：全宽，留边距
- 公司信息：单列堆叠
- 按钮：全宽显示

## 深色模式

### 颜色方案
- 背景：gray-800
- 文字：white
- 输入框：gray-700
- 边框：gray-600
- 主题色：保持一致

### 自动切换
- 跟随系统设置
- 无需手动配置
- 所有元素自动适配

## 键盘快捷键

- `Enter` (标签框) - 添加标签
- `Esc` (弹窗) - 关闭编辑 (需确认)
- `Tab` - 焦点切换
- `Shift+Tab` - 反向焦点切换

## 错误处理

### 网络错误
```
显示：Alert 对话框
内容："保存失败，请重试"
操作：关闭后可重新保存
```

### 验证错误
```
显示：输入框下方红色提示
内容：具体错误信息
操作：修正后可继续
```

### 服务器错误
```
显示：Alert 对话框
内容：详细错误信息
操作：联系管理员或稍后重试
```
