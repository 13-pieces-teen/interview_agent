# 面经编辑功能使用指南

本文档介绍如何使用面经卡片的编辑功能。

## 快速开始

### 1. 启动服务

首先确保后端服务正在运行：

```bash
# 在项目根目录
cd src/api
python app.py
```

然后启动前端服务：

```bash
# 在项目根目录
cd frontend
npm run dev
```

### 2. 访问面经详情

1. 在主界面点击"历史记录"按钮
2. 选择要查看的面经卡片
3. 进入面经详情页

### 3. 开始编辑

在面经详情页右上角，点击"编辑"按钮，进入编辑模式。

## 编辑功能详解

### 编辑公司信息

在编辑弹窗的"公司信息"部分，你可以修改：

- **公司名称**: 输入公司的完整名称
- **公司规模**: 从下拉菜单选择（大厂/中厂/小厂/初创）
- **职位**: 输入应聘的职位名称
- **面试阶段**: 从下拉菜单选择面试轮次

![公司信息编辑](./images/edit-company-info.png)

### 编辑面试体验

使用多行文本框描述：
- 面试流程
- 面试官风格
- 面试氛围
- 整体感受

```
示例：
面试体验很好，面试官专业且友善。
一共三轮技术面试：
1. 基础知识和算法
2. 项目经验深挖
3. 系统设计
整体氛围轻松，可以畅所欲言。
```

### 管理技术标签

#### 添加标签

1. 在"技术标签"输入框中输入标签名称
2. 按 `Enter` 键或点击 `+` 按钮添加
3. 标签会立即显示在下方

#### 删除标签

点击标签右侧的 `×` 图标即可删除。

#### 标签建议

- 使用简洁的关键词
- 技术栈：Python, React, Django, Redis
- 知识领域：算法, 数据结构, 系统设计
- 具体技术：GIL, 装饰器, Hooks

### 编辑面试问题

#### 修改现有问题

1. 找到要修改的问题卡片
2. 直接在文本框中编辑问题内容
3. 在下方的答案框中编辑或添加答案

#### 添加新问题

1. 点击"添加问题"按钮
2. 在新出现的问题卡片中输入问题
3. 填写对应的答案
4. 可以继续添加更多问题

#### 删除问题

1. 找到要删除的问题卡片
2. 点击右上角的垃圾桶图标
3. 在确认对话框中点击"确定"

### 保存修改

完成所有编辑后：

1. 检查修改内容是否正确
2. 点击右下角的"保存修改"按钮
3. 等待保存完成（会显示加载动画）
4. 自动返回详情页，查看更新后的内容

### 取消编辑

如果不想保存修改：

1. 点击"取消"按钮
2. 或点击右上角的关闭图标（×）
3. 所有未保存的修改将被丢弃

## 使用场景

### 场景 1: 补充遗漏的信息

在第一次处理面经时，AI 可能遗漏了一些信息：

1. 打开面经详情
2. 点击"编辑"
3. 补充公司规模、面试阶段等信息
4. 保存修改

### 场景 2: 添加自己的答案

对于没有原始答案的问题，可以添加你准备的答案：

1. 进入编辑模式
2. 找到没有答案的问题
3. 在答案框中输入你的答案
4. 保存修改

### 场景 3: 整理和优化问题

合并相似问题或删除重复问题：

1. 进入编辑模式
2. 删除重复的问题
3. 合并相似问题的内容
4. 重新组织问题顺序（如需要）
5. 保存修改

### 场景 4: 更新标签

根据实际面试内容优化技术标签：

1. 进入编辑模式
2. 删除不相关的标签
3. 添加更准确的技术关键词
4. 保存修改

## 键盘快捷键

- `Enter` - 在标签输入框中快速添加标签
- `Esc` - 关闭编辑弹窗（需确认）

## 注意事项

### 数据安全

- ✅ 所有修改会立即保存到数据库
- ✅ 点击"取消"不会保存任何修改
- ⚠️ 删除问题是不可逆的操作，请谨慎操作

### 最佳实践

1. **定期整理**: 建议处理完面经后立即检查和补充信息
2. **标签规范**: 使用统一的标签命名规范，便于后续筛选
3. **答案质量**: 自行添加的答案应该详细且准确
4. **及时保存**: 完成编辑后及时保存，避免数据丢失

### 常见问题

**Q: 编辑后的内容会影响原始数据吗？**
A: 是的，编辑会直接修改数据库中的数据。原始的 raw_content 字段保持不变。

**Q: 可以批量编辑多条面经吗？**
A: 目前不支持批量编辑，需要逐条编辑。

**Q: 删除的问题可以恢复吗？**
A: 目前不支持恢复已删除的问题，请谨慎操作。

**Q: 编辑时断网会怎样？**
A: 保存时如果网络断开会显示错误提示，修改不会丢失，可以重新点击保存。

**Q: 可以添加图片或附件吗？**
A: 目前仅支持文本编辑，暂不支持图片和附件。

## API 调用示例

如果你想通过 API 直接更新面经：

```bash
# 更新公司信息
curl -X PUT http://localhost:8000/api/experiences/{experience_id} \\
  -H "Content-Type: application/json" \\
  -d '{
    "company_name": "新公司名称",
    "company_scale": "大厂",
    "position": "高级工程师"
  }'

# 更新标签
curl -X PUT http://localhost:8000/api/experiences/{experience_id} \\
  -H "Content-Type: application/json" \\
  -d '{
    "tags": ["Python", "Django", "Redis"]
  }'

# 更新问题
curl -X PUT http://localhost:8000/api/experiences/{experience_id} \\
  -H "Content-Type: application/json" \\
  -d '{
    "questions": [
      {
        "id": "q1",
        "question": "问题内容",
        "answer": "答案内容",
        "has_original_answer": false,
        "tags": ["Python"]
      }
    ]
  }'
```
