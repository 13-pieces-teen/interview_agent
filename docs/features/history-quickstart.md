# 面经历史记录功能 - 快速开始

## 新功能说明

现在每次处理面经后，结果会自动保存到本地数据库。你可以通过网页右上角的"历史记录"按钮查看所有保存的面经，并支持强大的筛选功能。

## 启动步骤

### 1. 安装依赖（如果还没安装）

后端不需要额外依赖（SQLite是Python内置的）。

### 2. 启动服务

**Windows:**
```bash
.\start_dev.bat
```

**Linux/Mac:**
```bash
bash start_dev.sh
```

### 3. 访问网页

打开浏览器访问：`http://localhost:5173`

## 使用流程

### 第一次使用

1. **处理面经**：
   - 上传图片或粘贴文本
   - 点击"Process"按钮
   - 等待处理完成

2. **自动保存**：
   - 处理完成后，结果会自动保存
   - 无需任何手动操作

3. **查看历史**：
   - 点击右上角"历史记录"按钮
   - 看到刚才保存的面经卡片

### 浏览和筛选

1. **搜索公司**：
   ```
   在搜索框输入: "字节"、"阿里"、"腾讯" 等
   ```

2. **按标签筛选**：
   - 点击"筛选"按钮
   - 在"技术标签"区域选择感兴趣的标签
   - 如: RAG、强化学习、Agent、算法题

3. **按时间筛选**：
   - 最近7天
   - 最近30天
   - 最近90天

4. **查看详情**：
   - 点击任意卡片
   - 查看完整问题和答案
   - 点击"返回列表"回到画廊

## 功能特性

### ✅ 自动保存
每次处理完成后自动保存，无需手动操作

### ✅ 卡片展示
- 公司名称和规模
- 职位和面试阶段
- 问题数量和技术标签
- 创建日期

### ✅ 多维筛选
- 按公司名称
- 按技术标签（多选）
- 按时间范围
- 按面试阶段

### ✅ 统计数据
页面顶部显示：
- 总面经数量
- 总问题数量
- 涉及的公司数量

### ✅ 删除管理
鼠标悬停在卡片上，点击右上角删除图标

## 数据存储位置

```
data/interviews.db
```

建议定期备份此文件。

## 常见问题

**Q: 面经保存在哪里？**
A: 保存在项目根目录下的 `data/interviews.db` 文件中

**Q: 可以删除保存的面经吗？**
A: 可以，鼠标悬停在卡片上会显示删除按钮

**Q: 筛选没有结果？**
A: 点击"重置"按钮清除所有筛选条件，或者放宽筛选条件

**Q: 如何备份数据？**
A: 复制 `data/interviews.db` 文件即可
