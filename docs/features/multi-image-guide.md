# 多图片上传和粘贴功能说明

## 🎉 新功能特性

### 1. **多图片上传**
- 支持同时上传多张面试截图
- 拖拽多个文件到上传区域
- 点击选择多个图片文件
- 实时预览所有已选图片

### 2. **剪贴板粘贴**
- 按 **Ctrl+V** (Windows/Linux) 或 **Cmd+V** (Mac) 直接粘贴图片
- 支持从截图工具、浏览器等复制的图片
- 可连续粘贴多张图片
- 自动添加到上传列表

### 3. **图片管理**
- 每张图片独立显示缩略图
- 显示文件名和文件大小
- 悬停显示删除按钮
- 一键清除所有图片

---

## 📖 使用方法

### 方法 1：拖拽上传（推荐）

1. 打开网页界面 http://localhost:5173
2. 点击 **"Image Upload"** 标签
3. 从文件管理器中选中多张图片
4. **拖拽到虚线框内**
5. 看到图片缩略图后，点击 **"Process N Image(s)"**

### 方法 2：点击选择

1. 点击 **"Image Upload"** 标签
2. 点击虚线框区域
3. 在文件选择对话框中，按住 **Ctrl** 或 **Shift** 选择多个文件
4. 点击"打开"
5. 确认后点击 **"Process N Image(s)"**

### 方法 3：剪贴板粘贴（最快捷）

1. 使用截图工具（如 Snipping Tool、微信截图等）截取面试题
2. **无需保存**，直接复制到剪贴板
3. 切换到浏览器，确保在 **"Image Upload"** 标签页
4. 按 **Ctrl+V** 粘贴第一张图片
5. 重复步骤 1-4 粘贴更多图片
6. 点击 **"Process N Image(s)"**

### 方法 4：混合使用

你可以混合使用上述方法：
- 先拖拽几张图片
- 再用 Ctrl+V 粘贴更多图片
- 最后点击 "Add More Images" 选择其他文件
- 所有图片会合并到一个列表中

## 🎯 实际使用场景

### 场景 1：处理多页面试题截图

```
面试场景：你有 3 张截图
- 第一张：公司信息和职位
- 第二张：算法题1-3
- 第三张：算法题4-6

操作步骤：
1. 截图1 → Ctrl+V 粘贴
2. 截图2 → Ctrl+V 粘贴
3. 截图3 → Ctrl+V 粘贴
4. 看到 3 张缩略图
5. 点击 "Process 3 Image(s)"
6. 等待 OCR 和 AI 处理
7. 查看结构化结果
```

### 场景 2：整理历史面经截图

```
你的文件夹里有 10 张往期面试截图

操作步骤：
1. 点击 "Image Upload"
2. 点击虚线框
3. 按 Ctrl+A 全选图片（或 Ctrl 多选）
4. 点击"打开"
5. 预览所有 10 张图片
6. 如果某张不需要，悬停后点 X 删除
7. 点击 "Process 10 Image(s)"
```

### 场景 3：边截图边处理

```
一边看面经，一边截图处理

操作步骤：
1. 打开浏览器到上传页面
2. 看到题目1 → 微信截图 → Alt+Tab 切换 → Ctrl+V
3. 看到题目2 → 微信截图 → Alt+Tab 切换 → Ctrl+V
4. 看到题目3 → 微信截图 → Alt+Tab 切换 → Ctrl+V
5. 完成后一次性处理所有图片
```

## 🔧 技术细节

### 支持的图片格式

- PNG (.png)
- JPEG (.jpg, .jpeg)
- GIF (.gif)
- WebP (.webp)
- BMP (.bmp)

### 图片处理流程

```
多张图片 → OCR (逐个提取文本) → 合并文本 → AI 处理 → 结构化输出
```

**示例合并格式：**
```
=== Image 1: screenshot1.png ===
公司：字节跳动
职位：算法工程师
...

=== Image 2: screenshot2.png ===
问题1：二叉树的最大深度
答：使用递归...
...

=== Image 3: screenshot3.png ===
问题4：LRU缓存实现
...
```

### 性能优化

- **并行 OCR**: 所有图片同时进行 OCR
- **批量处理**: 合并后一次性调用 AI
- **自动清理**: 临时文件自动删除
- **预览优化**: 使用 blob URL 避免内存泄漏

## ⚠️ 注意事项

### 1. 图片数量建议

- **推荐**: 1-10 张图片
- **最大**: 无硬性限制，但处理时间随数量增加
- **超过 10 张**: 建议分批处理

### 2. 处理时间估算

| 图片数量 | 预计时间 |
|---------|---------|
| 1 张 | 5-10秒 |
| 3 张 | 15-25秒 |
| 5 张 | 25-40秒 |
| 10 张 | 50-80秒 |

### 3. 图片质量要求

- **清晰度**: 文字清晰可辨
- **大小**: 每张 < 5MB 推荐
- **内容**: 尽量只包含面试相关内容
- **旋转**: 确保图片方向正确

### 4. 错误处理

如果某张图片 OCR 失败：
- 系统会标记错误但继续处理其他图片
- 结果中会显示该图片的错误信息
- 不会影响其他图片的处理

## 🎓 最佳实践

### ✅ 推荐做法

1. **按主题分组**: 相关的题目截图放一起处理
2. **命名规范**: 给文件取有意义的名字（如 "bytedance-round1.png"）
3. **检查预览**: 提交前快速浏览缩略图
4. **清理图片**: 删除模糊或不需要的图片
5. **启用答案生成**: 如果截图只有题目没有答案

### ❌ 不推荐做法

1. **一次上传太多**: 避免 20+ 张图片一起处理
2. **图片过大**: 避免上传原始截图（可先压缩）
3. **包含个人信息**: 截图前遮挡敏感信息
4. **图片不清晰**: OCR 无法识别会导致结果不准确

## 🐛 常见问题

### Q1: 粘贴不生效？

**原因**: 没有在 Image Upload 标签页
**解决**: 确保点击了 "Image Upload" 按钮

### Q2: 图片没有缩略图？

**原因**: 浏览器不支持或文件格式问题
**解决**: 尝试转换为 PNG 或 JPG 格式

### Q3: 处理很慢？

**原因**: 图片太多或单张图片太大
**解决**:
- 减少图片数量
- 压缩图片大小
- 等待更长时间

### Q4: OCR 结果不准确？

**原因**: 图片质量问题
**解决**:
- 使用更清晰的截图
- 确保文字不要太小
- 避免手写字体

### Q5: 能处理 PDF 吗？

**回答**: 目前只支持图片，需要先将 PDF 转为图片

## 💡 使用技巧

### 技巧 1: 快速批量处理

使用 **Windows + Shift + S** 或其他截图工具：
1. 截图1 → 自动复制到剪贴板

3. 截图2 → Ctrl+V

- 电脑本地文件（点击选择）

提交前检查：
- 文件名是否正确
- 缩略图是否清晰
- 数量是否完整
- 顺序是否合理
