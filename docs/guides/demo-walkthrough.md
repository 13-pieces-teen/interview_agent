# 多图片上传功能演示

## 🎬 功能演示场景

### 演示 1: Ctrl+V 粘贴多张图片

```
场景：用户有3张微信截图需要处理

步骤：
┌────────────────────────────────────┐
│ 1. 打开浏览器到上传页面             │
│    → http://localhost:5173         │
│    → 点击 "Image Upload"           │
└────────────────────────────────────┘
              ↓
┌────────────────────────────────────┐
│ 2. 微信截图第一张面试题             │
│    → 截图自动复制到剪贴板           │
│    → Alt+Tab 切回浏览器            │
│    → 按 Ctrl+V                     │
│    → 🎉 图片1出现在预览区          │
└────────────────────────────────────┘
              ↓
┌────────────────────────────────────┐
│ 3. 继续截图第二张                   │
│    → 微信截图                       │
│    → Alt+Tab                       │
│    → Ctrl+V                        │
│    → 🎉 图片2添加到列表            │
└────────────────────────────────────┘
              ↓
┌────────────────────────────────────┐
│ 4. 截图第三张                       │
│    → Ctrl+V                        │
│    → 🎉 图片3添加                  │
│    → 看到 "Image Upload (3)"       │
└────────────────────────────────────┘
              ↓
┌────────────────────────────────────┐
│ 5. 点击 "Process 3 Image(s)"       │
│    → 显示加载动画                   │
│    → "Processing 3 image(s)..."    │
└────────────────────────────────────┘
              ↓
┌────────────────────────────────────┐
│ 6. 查看结果 ✅                      │
│    → 所有题目已提取                 │
│    → 结构化显示                     │
│    → 可下载 JSON/Markdown          │
└────────────────────────────────────┘
```

**效果**: 无需保存文件，3次粘贴完成上传！

```

│    → 找到截图文件夹                 │

│      • screenshot2.png             │
│      • screenshot3.png             │
│      • screenshot4.png             │
│      • screenshot5.png             │
└────────────────────────────────────┘
              ↓
┌────────────────────────────────────┐
│ 2. 拖拽到浏览器上传区               │
│    → 鼠标按住文件                   │
│    → 拖到虚线框                     │
│    → 松开鼠标                       │
│    → 🎉 5张图片全部显示             │
└────────────────────────────────────┘
              ↓
┌────────────────────────────────────┐
│ 3. 预览所有图片                     │
│    ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ │
│    │ 1 │ │ 2 │ │ 3 │ │ 4 │ │ 5 │ │
│    └───┘ └───┘ └───┘ └───┘ └───┘ │
│    每张显示缩略图、文件名、大小      │
└────────────────────────────────────┘
              ↓
┌────────────────────────────────────┐
│ 4. 如果某张不需要                   │
│    → 悬停在图片3上                  │
│    → 出现 [X] 按钮                 │

│    → 剩余 4 张                     │

┌────────────────────────────────────┐

│    → 处理中...                      │
│    → 完成！查看结果                 │
└────────────────────────────────────┘
```

**效果**: 批量选择，一次拖拽，全部上传！

### 演示 3: 混合使用多种方式

```
场景：部分图片在电脑，部分要截图

步骤：
┌────────────────────────────────────┐
│ 1. 先点击虚线框选择2张本地文件      │
│    → 选择 image1.png, image2.png   │
│    → 打开                           │
│    → 显示 "Image Upload (2)"       │
└────────────────────────────────────┘
              ↓
┌────────────────────────────────────┐
│ 2. 现在需要截图新内容               │
│    → 微信截图                       │
│    → Ctrl+V 粘贴                   │
│    → 图片3添加                      │
│    → "Image Upload (3)"            │
└────────────────────────────────────┘
              ↓
┌────────────────────────────────────┐
│ 3. 想起还有图片在桌面               │
│    → 点击 "Add More Images"        │
│    → 选择 desktop_image.png        │
│    → 图片4添加                      │
└────────────────────────────────────┘
              ↓
┌────────────────────────────────────┐
│ 4. 再从浏览器复制一张图             │
│    → 右键图片 → 复制图片            │
│    → 切回页面                       │
│    → Ctrl+V                        │
│    → 图片5添加                      │
│    → "Image Upload (5)"            │
└────────────────────────────────────┘
              ↓
┌────────────────────────────────────┐
│ 5. 处理所有图片                     │
│    → "Process 5 Image(s)"          │
│    → 等待结果                       │
└────────────────────────────────────┘
```

**效果**: 灵活组合，满足各种场景！

## 🎯 关键交互点

### 交互 1: 粘贴反馈
```
用户按 Ctrl+V
    ↓
检测剪贴板内容
    ↓
如果是图片:
  → ✅ 添加到列表
  → 显示缩略图
  → 更新计数
    ↓
如果不是图片:
  → ⚠️ 无反应（或提示）
```

### 交互 2: 删除图片
```
鼠标悬停在图片上
    ↓
显示深色遮罩层
    ↓
显示红色 [X] 按钮
    ↓
点击 [X]
    ↓
图片移除
    ↓
更新计数和预览
```

### 交互 3: 拖拽反馈
```
拖入文件
    ↓
虚线框变蓝色
    ↓
显示 "Drop images here..."
    ↓
松开鼠标
    ↓
文件添加
    ↓
恢复正常样式
```
