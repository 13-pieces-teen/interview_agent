# 双视图模式功能说明

## 功能概述

面经整理工具现在支持两种展示模式，方便用户从不同角度查看和检索面经内容：

### 1. 按面经排列（默认模式）

- **展示方式**：以面经为单位，每条面经显示为一个卡片
- **适用场景**：浏览某个公司的完整面试经历，了解整体面试流程
- **主要功能**：
  - 查看面经基本信息（公司、职位、阶段等）
  - 按公司名称搜索
  - 按时间范围筛选（7天、30天、90天）
  - 按面试阶段筛选
  - 按技术标签筛选

### 2. 按题目排列（新增）

- **展示方式**：以题目为单位，相同题目聚合在一起
- **适用场景**：准备面试时查看某个题目在不同公司的回答，了解高频面试题
- **主要功能**：
  - 显示题目出现次数
  - 查看题目在不同公司的所有回答
  - 按题目内容搜索
  - 按技术标签筛选
  - 按公司名称筛选
  - 展开查看题目的所有出现记录

## 使用方法

### 切换视图模式

在历史记录页面顶部，点击视图模式切换按钮：

- 🔲 **按面经排列**：查看完整的面经列表
- 📋 **按题目排列**：查看题目聚合视图

### 按题目视图的特点

1. **题目聚合**：相同或相似的题目会聚合在一起，显示出现次数
2. **展开详情**：点击题目可展开，查看该题目在不同面经中的所有出现记录
3. **多维度筛选**：
   - 在搜索框输入关键词搜索题目内容
   - 使用技术标签筛选特定领域的题目
   - 按公司名称筛选某个公司的面试题
4. **回答对比**：可以对比同一题目在不同公司、不同场景下的回答

### 题目展开后的信息

每个题目展开后会显示所有出现记录，包括：
- 🏢 公司名称
- 💼 职位信息
- 📝 面试阶段
- 📅 面试时间
- 💬 原始回答或AI生成的参考答案

点击任何一条记录可以跳转到完整的面经详情。

## 使用场景示例

### 场景 1：准备某公司面试

1. 切换到"按面经排列"模式
2. 在搜索框输入公司名称
3. 查看该公司的所有面经
4. 了解面试流程和常见问题

### 场景 2：针对性准备某个知识点

1. 切换到"按题目排列"模式
2. 在搜索框输入知识点关键词（如"Redis"、"算法"）
3. 查看相关题目的高频出现情况
4. 展开题目查看不同公司的回答

### 场景 3：查看高频面试题

1. 切换到"按题目排列"模式
2. 不使用任何筛选条件
3. 题目会按出现次数从高到低排序
4. 优先准备出现次数多的题目

## API 接口

### 获取题目聚合数据

```http
GET /api/questions/grouped?search=xxx&tags=tag1,tag2&company_name=xxx&limit=100
```

**参数说明**：
- `search`: 题目内容搜索关键词
- `tags`: 技术标签（逗号分隔）
- `company_name`: 公司名称
- `limit`: 返回数量限制
- `offset`: 分页偏移量

**响应格式**：
```json
{
  "total": 50,
  "groups": [
    {
      "question": "题目内容",
      "count": 5,
      "tags": ["Python", "算法"],
      "occurrences": [
        {
          "experience_id": "xxx",
          "company_name": "字节跳动",
          "position": "后端开发",
          "interview_stage": "一面",
          "answer": "回答内容",
          "has_original_answer": true,
          "created_at": "2024-01-01T00:00:00"
        }
      ]
    }
  ]
}
```

## 技术实现

### 前端组件

- **ExperienceGallery**: 主容器组件，负责视图切换和数据加载
- **ExperienceCard**: 面经卡片组件（按面经视图）
- **QuestionGroupView**: 题目聚合视图组件（按题目视图）

### 后端实现

- **数据聚合**：`Database.get_grouped_questions()` 方法实现题目聚合逻辑
- **搜索过滤**：支持题目内容搜索、标签过滤、公司过滤
- **性能优化**：使用内存聚合，适合中小规模数据集

## 注意事项

1. 题目聚合基于完全匹配，相同题目的不同表述会被视为不同题目
2. 在题目视图中，时间范围和面试阶段筛选器会被隐藏（不适用）
3. 题目按出现次数降序排列，高频题目会优先显示
4. 标签筛选在两种视图中都可用，可以快速定位特定技术领域
